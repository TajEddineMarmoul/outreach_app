## Shared direction

- Preserve the existing white, navy, and blue style.
- Keep main navigation and Help inside Menu.
- Show the essential task first, with secondary tools behind closed menus.
- Use compact, readable controls and avoid unnecessary simultaneous panels.
- Keep campaign-builder steps out of these top-level library and settings pages.
- Do not introduce TrackMailBox, required-attachment settings, or unsupported tracking metrics.

The analytics chart illustrates a possible presentation of delivery counts; it is not a claim that this chart has already been implemented.
